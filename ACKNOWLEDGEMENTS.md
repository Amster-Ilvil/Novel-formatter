# Acknowledgements / 致谢

Novel Formatter builds on the work of the open-source and platform communities around OCR, document processing, desktop UI, and ebook production.

特别感谢以下项目与官方平台能力为本项目提供实现基础、接口或工程参考：

- Qt for Python / PySide6 — desktop GUI framework.
- Apple Vision — native OCR and vision capabilities on macOS.
- PaddleOCR — general-purpose OCR and layout-recognition ecosystem.
- NDLOCR / NDLOCR-Lite — Japanese book OCR and layout-recognition reference.
- Manga Image Translator — manga/Japanese OCR and related integration ideas.
- PyMuPDF — PDF rendering and document processing.
- Pillow — image loading and preprocessing.
- python-docx — DOCX reading and generation.
- Open Model Zoo and related handwriting-recognition resources.
- jlect-jhr — Japanese handwriting-recognition auxiliary resources.

更多项目级引用与说明见 `README.md` 中的“参考项目与引用”章节，以及仓库内对应 third-party license 文件。
